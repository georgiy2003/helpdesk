# HelpDesk

[![Build](https://github.com/georgiy2003/helpdesk/actions/workflows/deploy.yml/badge.svg)](https://github.com/georgiy2003/helpdesk/actions/workflows/deploy.yml)

[Открыть приложение на GitHub Pages](https://georgiy2003.github.io/helpdesk/)

Запуск frontend

npm install
npm run build

Запуск backend

Backend находится в каталоге netology-homeworks/http/helpdesk/backend исходного репозитория Netology.

npm install
npm start

После запуска backend доступен по адресу http://localhost:7070.
